1. آماده‌سازی پروژه برای GitHub

۱.۱ فایل‌های غیرضروری حذف/ایگنور شده‌اند

✅ .gitignore بروزرسانی شد. فایل‌های زیر از قبل در .gitignore قرار دارند و push نمی‌شوند:
  • node_modules/, .next/, .env
  • skills/ (61MB), tool-results/, upload/
  • db/*.db (فایل دیتابیس SQLite)
  • dev.log, *.tar, .zscripts/

۱.۲ ساخت Repository در GitHub

  1. به github.com/new بروید
  2. نام ریپازیتوری: mercury-gp
  3. Private یا Public (دومنه اختصاصی نیاز به پلن Pro نیست)
  4. ❌ نتیجه «Initialize with README», «.gitignore», «LICENSE» را تیک نزنید
  5. Create رو بزنید

۱.۳ Push کد به GitHub

cd /path/to/mercury-gp-project

git init
git add .
git commit -m "Initial commit: Mercury GP website"

git remote add origin https://github.com/YOUR_USERNAME/mercury-gp.git
git branch -M main
git push -u origin main

2. تنظیم Vercel

۲.۱ اتصال GitHub به Vercel

  1. به vercel.com/new بروید
  2. وارد حساب GitHub شوید و ریپازیتوری mercury-gp را انتخاب کنید
  3. Framework Preset: Next.js (خودکار تشخیص می‌دهد)

۲.۲ تنظیمات Build

تنظیممقدار
Framework PresetNext.js
Build Commandnpx prisma generate && next build
Output Directory.next
Install Commandnpm install (پیش‌فرض)
Node.js Version20.x
⚠️ مهم: Build Command
حتماً npx prisma generate قبل از next build باشد تا Prisma Client ساخته شود.

۲.۳ متغیرهای محیطی (Environment Variables)

ناممقدارالزامی؟
NEXT_PUBLIC_BASE_URLhttps://lasermercury.ir✅ بله
DATABASE_URLببینید بخش ۲.۴اختیاری

در Vercel: Settings → Environment Variables → اضافه کنید برای Production + Preview + Development

۲.۴ دیتابیس (موضوع مهم)

⚠️ SQLite در Vercel کار نمی‌کند — Vercel Serverless است و فایل‌سیستم موقت دارد.
راه‌حل: فرم تماس (تنها بخشی که از دیتابیس استفاده می‌کند) بدون دیتابیس هم کار می‌کند — پیام‌ها در console.log ذخیره می‌شوند. برای دیتابیس واقعی، یکی از گزینه‌های زیر را انتخاب کنید:
گزینههزینهپیچیدگیلینک
بدون دیتابیس (فقط console.log) رایگان هیچ فعلاً همین کار می‌کند ✅
Turso (SQLite سرورلس) رایگان 500 DB کم — совместیم با Prisma turso.tech
Vercel Postgres (Neon) رایگان متوسط — نیاز تغییر schema docs

3. اتصال دامنه

۳.۱ در Vercel

  1. پروژه Vercel → Settings → Domains
  2. دامنه lasermercury.ir را اضافه کنید
  3. Vercel دو رکورد DNS نشان می‌دهد:
TypeNameValue
A@76.76.21.21
CNAMEwwwcname.vercel-dns.com

۳.۲ در پنل DNS دامنه

  1. وارد پنل DNS ثبت‌کننده دامنه شوید
  2. رکوردهای بالا را اضافه کنید
  3. SSL خودکار توسط Vercel فعال می‌شود (پس از ۵-۱۰ دقیقه)

6. سؤالات متداول

آیا نیاز به تغییر کد دارم؟

خیر — همه چیز آماده است. فقط فایل‌های جدید (.env.example, deployment-guide.html) را اضافه کردم و .gitignore و API تماس را بهینه‌سازی کردم.

آیا Vercel رایگان است؟

بله — پلن Hobby رایگان شامل: دامنه اختصاصی، SSL، 100GB bandwidth، Serverless Functions.

اگر دامنه ندارم چی؟

Vercel یک آدرس your-project.vercel.app رایگان می‌دهد. بعداً دامنه اضافه کنید.

Bun در Vercel پشتیبانی می‌شود؟

Vercel از npm استفاده می‌کند (Build Command). نیازی به نصب Bun روی Vercel نیست.
