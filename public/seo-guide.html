1. Google Search Console ✅ Active

src/app/layout.tsx

Verify domain ownership and submit sitemap to Google.

  1. Go to Google Search Console and add your domain property (lasermercury.ir).
  2. Choose "HTML tag" verification method. Copy the meta tag content value.
  3. In layout.tsx, find the verification.google field and replace the placeholder: 
    verification: {
  google: "YOUR_VERIFICATION_CODE_HERE",  // ← paste here
  yandex: "YOUR_YANDEX_CODE_HERE",
}
  4. After deploying, click "Verify" in Search Console.
  5. Go to Sitemaps and submit: https://lasermercury.ir/sitemap.xml
  6. Also submit RSS feed for faster content discovery: https://lasermercury.ir/feed.xml

2. Google Analytics 4 (GA4) ⏳ Needs Config

src/app/layout.tsx

Track visitors, pageviews, and user behavior.

  1. Go to Google Analytics and create a GA4 property for lasermercury.ir.
  2. Copy your Measurement ID (starts with G-).
  3. In layout.tsx, uncomment the GA4 scripts and replace the ID: 
    <!-- In <head> section -->
<Script
  src="https://www.googletagmanager.com/gtag/js?id=G-YOUR_ID"
  strategy="afterInteractive"
/>

<!-- In <body> section -->
<Script id="ga4-init" strategy="afterInteractive">
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag("js", new Date());
  gtag("config", "G-YOUR_ID");
</Script>
  4. Verify data appears in GA4 Realtime report within 24 hours.

3. Google Tag Manager (GTM) ⏳ Needs Config

src/app/layout.tsx

Centralized tag management for analytics, ads, and conversion tracking.

  1. Go to Google Tag Manager and create a new container for lasermercury.ir.
  2. Copy your Container ID (starts with GTM-).
  3. In layout.tsx, uncomment the GTM scripts and replace the ID: 
    <!-- In <head> section -->
<Script id="gtm" strategy="afterInteractive">
  (function(w,d,s,l,i){w[l]=w[l]||[];w[l].push({'gtm.start':
  new Date().getTime(),event:'gtm.js'});var f=d.getElementsByTagName(s)[0],
  j=d.createElement(s),dl=l!='dataLayer'?'&l='+l:'';j.async=true;j.src=
  'https://www.googletagmanager.com/gtm.js?id='+i+dl;f.parentNode.insertBefore(j,f);
  })(window,document,'script','dataLayer','GTM-YOUR_ID');
</Script>
  4. Set up GA4, Facebook Pixel, and conversion events as tags inside GTM.
